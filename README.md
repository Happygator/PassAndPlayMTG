# Pass-And-Play MTG

A pass-and-play web app for 1v1 Magic: The Gathering sealed micro-formats on a **single shared device** — open it on one phone, pass the phone back and forth, and play.

Two modes are built in:

- **3-Card Blind** — each player opens a small sealed pool and builds 3-card decks. Decks are revealed at match time, and because 3CB has perfect information, players *discuss* each pairing as a 2-game match (each player on the play once) and record the result.
- **Pai Gow MTG** — same skeleton, but decks stay face-down at match time and are revealed card by card as you actually play a best-of-one; results are simply win / draw / loss.

## Get it on your phone (easiest way)

This project is a web app you install from the browser:

1. On the phone, open **<https://happygator.github.io/PassAndPlayMTG/>**.
2. Add it to the home screen:
   - **iPhone / iPad:** open the link in **Safari** (not Chrome), tap **Share**, then **Add to Home Screen**.
   - **Android:** open it in **Chrome** and tap the **Install** button on the start screen (or ⋮ menu → *Install app*).
3. Launch it from the new icon. It runs full-screen and, after the first load, **works completely offline** — every card image is stored on the phone.

When a new version is published, the start screen shows an "A new version is available — Reload" notice; tap it to update.
